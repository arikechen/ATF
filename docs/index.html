AT.field 是原生 macOS AI 終端控制台，整合 Claude Code、Codex CLI、Gemini CLI、aider、SSH、Serial port、Git diff、localhost preview 與 AI Agent 工作流。當 AI 在終端裡改檔案、產生報告或啟動網頁時，你可以直接在右側 Sidecar 查看結果，不用一直切換 Finder、瀏覽器、Preview 或 VS Code。

一個地方處理所有 terminal 工作

真實 App 截圖展示 Sidecar 預覽、Git diff、localhost、SSH、Serial、split terminal 與浮動視窗。

01 · 三欄駕駛艙

Navigator · Core · Sidecar，開發盡在一窗

左側 Files 導覽器快速瀏覽專案、中央 Core 執行指令、右側 Sidecar 即時渲染 Markdown 文件。三欄同時運作，終端與預覽不再分離。

02 · Sidecar 雙模式

Preview ↔ Edit 一鍵切換

右側 Sidecar 支援 Preview（Markdown 即時渲染）與 Edit（原始碼直接編輯）雙模式。選取檔案立刻看、立刻改，不需要另開編輯器。

03 · 專案總覽 & Git

完整專案樹＋Git Diff 直進 Sidecar

左側導覽器展開多層專案結構（ATF / atf-mcp / website / scripts），git diff 結果直接送進右側 Sidecar 渲染成帶顏色的 diff 預覽，不用切換 Source Control app。

04 · WebKit Sidecar

localhost 一鍵進 Sidecar 瀏覽器

終端機偵測到 URL 後，一鍵在右側 WebKit 沙箱開啟。npm run dev、vite、任何 HTTP 服務啟動後即可預覽，改一行、看一次，雙手不離鍵盤。

05 · SSH & Serial

SSH & Serial，統一連線中心

把 SSH host 與 Serial device（/dev/tty.*）當成同一級 session 管理。切換 tab 不會中斷背景連線，適合 embedded、robotics、homelab 與 infra 工作。

06 · Split Terminal

一個 Tab，多個終端並排

⌘D 即可水平分割終端機，每個 pane 獨立 PTY session。對照多台機器輸出或並排執行不同指令，都不需要另開視窗。

07 · Detach & Pin

Tab 獨立成浮動視窗，釘在最上層

把任意 Tab 拖出主視窗，成為獨立浮動的終端機視窗。右上角圖釘可釘在所有 Space 最上層，SSH 連線或長跑腳本永遠不被其他視窗遮擋。

核心功能

保留 terminal-first 工作流，加入檔案預覽、diff 審查、localhost 預覽、SSH / Serial 管理與 MCP automation。

三欄式控制台

Navigator、terminal、Sidecar 在同一個視窗中協作。左側管理檔案與連線，中間執行指令，右側查看結果。

Sidecar 預覽 / 編輯

預覽 Markdown、圖片、影片、HTML、JSON、PDF，也能編輯原始碼並支援語法高亮。

SSH & Serial 中心

將 SSH host 與 Serial device（/dev/tty.*）當成同一級 session 管理，切換 tab 不會中斷背景連線。

終端輸出偵測

從 terminal output 偵測檔案路徑、localhost URL、圖片、PDF、HTML、diff，並直接在 Sidecar 開啟。

macOS 原生技術規格

AT.field 使用 SwiftUI + AppKit 建構，保留 macOS 原生體驗，避免 Electron 工具常見的資源負擔。
